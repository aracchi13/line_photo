スタッフ向け

管理画面の使い方

1

管理画面を開く

以下の URL にアクセスしてください。ブックマークに登録しておくと便利です。

📌 管理画面 URL（スタッフ専用）：
https://script.google.com/macros/s/AKfycbwRshm0x5j2QvSMAULQKLd3D6SfLw8nZhucV05T8LtrEDkqn37eAsgDvVtRn8XirZFN/exec?page=admin
2

新しい案件を作成する

画面上部の入力欄に案件名を入力して「作成」ボタンを押します。

案件名の例
山田様邸 外壁工事作成
鈴木様 ビフォーアフター撮影作成
✅ 確認ダイアログが表示されます。内容を確認してから「作成する」を押してください。
作成すると Google Drive に同名のフォルダが自動で作られます。
3

アップロード URL をコピーしてお客様に送る

案件一覧に表示されている URL の横の「コピー」ボタンを押すとクリップボードに入ります。
そのまま LINE やメール等でお客様に貼り付けて送信してください。

https://script.google.com/macros/s/xxx?caseId=yyy コピー
⚠️ URL はそのまま長文になります。短縮 URL サービス（bit.ly 等）を使うと LINE で送りやすくなります。
4

Google Drive で写真を確認する

各案件カードの「Driveを開く」ボタンを押すと、その案件のフォルダが直接開きます。

📁 山田様邸 外壁工事 ✏️ 名前を変更 Driveを開く
5

案件名を変更する（任意）

「✏️ 名前を変更」ボタンを押すと入力欄が表示されます。新しい名前を入力して「保存」を押してください。
Google Drive のフォルダ名も同時に変更されます。

お客様向け

写真の送り方

スタッフから送られてきた URL をタップすると写真送信ページが開きます。
管理画面でコピーした案件ごとの URL をお客様に送ってください。

📎 お客様向けアップロード URL の例（管理画面からコピーして送付）：
https://script.google.com/macros/s/AKfycbwRshm0x5j2QvSMAULQKLd3D6SfLw8nZhucV05T8LtrEDkqn37eAsgDvVtRn8XirZFN/exec?caseId=【案件ID】
※ 案件IDは管理画面の「コピー」ボタンで自動的に付与されます。手動入力は不要です。
1

Safari または Chrome で URL を開く

LINE のトーク画面から URL をタップしてください。

⚠️ LINE 内のブラウザでは写真を選べません。
画面に案内が表示されたら、右下の「・・・」→「ブラウザで開く」を選んでください。
（Android の場合は自動で Chrome が起動します）
2

写真を選ぶ

画面中央の点線のエリアをタップするとカメラロールが開きます。
送りたい写真を複数選んでも OK です。

📱 選んだ写真はサムネイルでプレビュー表示されます。
3

「アップロードする」ボタンを押す

緑色のボタンが表示されたらタップしてください。
進行状況がバーで表示されます（例：2 / 5枚）。

4

「✅ 〇枚送信完了！」と表示されたら完了

写真がスタッフの Google Drive に届きました。
失敗した場合はメッセージが赤く表示されます。もう一度ボタンを押すと再送信できます。

📸 ポイント：写真は元の画質のままアップロードされます。圧縮されないので、細部まできれいに届きます。

FAQ

よくある質問

QLINE で URL を送ったら「ブラウザで開く」が出ない
A画面右下の「…」（3点メニュー）をタップすると選択肢が出ます。それでも出ない場合は URL をコピーして Safari のアドレスバーに貼り付けてください。
Qアップロードに時間がかかる
A写真の枚数が多いほど時間がかかります。Wi-Fi 環境での利用を推奨します。画面を閉じずにお待ちください。
Q一部の写真だけ失敗した
A「⚠️ 〇枚失敗しました」と表示されたら、もう一度ボタンを押すと失敗分のみ再送信されます。
Q同じ URL を何度も使える？
Aはい。同じ案件 URL は何度でも使えます。追加で写真を送りたいときも同じ URL を使ってください。
Q間違えて別の案件 URL を送ってしまった
A管理画面から正しい URL をコピーして、お客様に再送してください。
Q通知メールを受け取るアドレスを変えたい
Aコード.gs の NOTIFY_EMAILS リストを変更し、再デプロイしてください。
